# 📻 Cross-Platform Stream Radio Player

Легкий, автономний та кросплатформенний радіоплеєр, написаний на **Rust**.

Проєкт розроблено з акцентом на мінімалістичність, низьке споживання ресурсів та зручну інтеграцію в Linux-оточення (зокрема **Sway / Waybar** через Freedesktop StatusNotifierItem), з можливістю збірки під **Windows** та **Android**.

---

## ⚙️ Основні можливості

* **Автономний аудіо-рушій:** Відтворення потоків без зовнішніх залежностей (без `mpv` чи `vlc`).
* **Підтримка форматів:** MP3, AAC, OGG (Vorbis / Opus), FLAC.
* **Інтеграція в системний трей (Waybar / SNI):**
  * **ЛКМ:** Показати / сховати головне вікно.
  * **СКМ:** Швидкий старт / пауза (Play / Pause).
  * **ПКМ:** Контекстне меню (Вибір станцій, налаштування, вихід).
  * **Колесо миші (Scroll):** Зміна гучності з захисним бар'єром.
* **Захист слуху (Safety Volume Limit):**
  * Плавна зміна гучності кроком **2%**.
  * Бар'єр на рівні **70%** (зупинка регулювання).
  * Мікро-крок **1%** після підтвердженого перетину бар'єру.
* **ICY-метадані:** Зчитування назви виконавця та композиції в реальному часі.
* **Менеджер станцій:** Збереження та вибір радіостанцій через зручний ComboBox.

---

## 🎛️ Змінні та Конфігурація (`config.toml`)

Додаток зберігає налаштування у файлі конфігурації (на Linux: `~/.config/radio-player/config.toml`).

### Структура конфігу та змінні:

| Змінна | Тип | За замовчуванням | Опис |
| :--- | :--- | :--- | :--- |
| `volume` | `f32` | `0.5` | Поточний рівень гучності (від `0.0` до `1.0`). |
| `volume_safety_limit` | `f32` | `0.7` | Поріг безпечної гучності (70%). |
| `volume_step_normal` | `f32` | `0.02` | Звичайний крок змінення гучності (2%). |
| `volume_step_fine` | `f32` | `0.01` | Мікро-крок у зоні високої гучності (1%). |
| `last_station_url` | `String` | `""` | URL-адреса останньої відтворюваної станції. |
| `stations` | `Array` | `[...]` | Список збережених радіостанцій (`name`, `url`). |

#### Приклад `config.toml`:
```toml
volume = 0.45
volume_safety_limit = 0.70
volume_step_normal = 0.02
volume_step_fine = 0.01
last_station_url = "[http://ua.jtradio.net/live192](http://ua.jtradio.net/live192)"

[[stations]]
name = "JT Radio"
url = "[http://ua.jtradio.net/live192](http://ua.jtradio.net/live192)"

[[stations]]
name = "Radio Bayrak"
url = "[https://example.com/stream.ogg](https://example.com/stream.ogg)"
